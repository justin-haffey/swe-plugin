# swe-implement

Apply [the delivery contract](../../references/ARTIFACT-CONTRACT.md). Human approval is default; preserve named Major human decisions, independence and the two-cycle limit.

Select inputs before coding: standalone accepted local FEATURE.md with approach, or its linked accepted Design; federated accepted upstream Feature/allocation plus accepted local Design. A Plan is required only when the canonical allocation uses one. Preserve legacy requirements for unadopted work.

Verify relevant architecture, actual prerequisites, risk and owned paths. Follow ancestry only for an unresolved fact; no copied full-chain packet. Unknown prerequisites block affected work. Implement coherent scope including tests/docs. Request swe-test checks; developers fix source/tests and request affected reruns. Use native tester, actual checkout and serialized shared outputs.

Write [EVIDENCE.md](references/EVIDENCE-TEMPLATE.md) beside local Feature/Design. Link receipts; author changed behavior, deviations, interpretation and obligations. Generate provenance, never copy logs. Separate implementation/verification/acceptance; missing observations keep Evidence Draft and failures cannot pass. Changes to approved intent or architecture return for a successor decision.

Hand evidence to independent solution-validator. No deployment, external mutation or Git operations are implied.
