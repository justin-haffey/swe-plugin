# Research

Apply [the delivery contract](../../references/ARTIFACT-CONTRACT.md).

Resolve the governing local Feature, optional Epic or explicit research question. Reuse current findings; investigate only unresolved material uncertainty. Use references/RESEARCH-TEMPLATE.md beside the owning work when a durable report is useful; otherwise return bounded findings into that work. Record sources, freshness, fact/inference, limitations and decision implications. Complete research is evidence, not approval. Never manufacture a portfolio or Epic. Repository execution checks route through swe-test.
