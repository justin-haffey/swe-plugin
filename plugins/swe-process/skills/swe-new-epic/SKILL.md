# swe-new-epic

Apply [the delivery contract](../../references/ARTIFACT-CONTRACT.md). Human approval is default; preserve named Major human decisions, independence and the two-cycle limit.

Use an Epic only for genuine related-feature coordination; standalone Features do not require one.

Resolve authority/outcome, allocate next EPIC-NNN under `.swe/epics/NNN-short-name/` and use [EPIC-TEMPLATE.md](references/EPIC-TEMPLATE.md). Define stable EO-NNN outcomes, constraints and actual participants; never invent parent Platform or additional solutions. Create subdirectories only as needed. Review intent under effective policy; return decision and next useful action. Do not implement from an Epic alone.
