# Architecture Analysis

Place each strategic software-architecture analysis at:

```text
architecture/analysis/<scope-key>/ANALYSIS.md
```

`<scope-key>` is a stable, repository-relative slug for the analyzed platform, system view, component, package, module, feature, or other bounded subject. Reuse the same location only when the caller explicitly authorizes replacing its existing report.

These reports analyze existing engineering artifacts and source evidence. They are advisory: recommendations must enter the normal Concept, architecture, ADR, contract, Feature, plan, design, implementation, and validation governance before becoming authoritative. An analysis must not modify the artifacts it examines.
